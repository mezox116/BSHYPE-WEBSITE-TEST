ABOUT HYPE.

A BombSquad community for players, creators and friends.

01 / OUR STORY

IN THE GAME SINCE 2019

HYPE presents itself as a European and African BombSquad community active since 2019. Its community description highlights friendly players, quality game servers and a place to hang out whether you play BombSquad or simply want to connect with people.

The Discord server directory currently lists the server as established on April 2, 2021. This is a separate directory date; HYPE's own public description and website use 2019 as the community's “since” year.
